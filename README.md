# Battle Arts: Martial Arts

Дополнение к **Epic Fight - Battle Arts** (Minecraft 1.20.1 Forge): шесть рукопашных стилей боя со своими
боевыми искусствами. Всё управление — клавиши Epic Fight и Battle Arts, своих клавиш нет.

## Что нужно

- Epic Fight 20.14.x, Battle Arts API (и сам Battle Arts по желанию)

## Стили боя (слот Battle Style)

| Стиль | Особенность | Боевое искусство (Z) |
|---|---|---|
| Боксёр | быстрые руки, добивание-двойка | Сокрушающий апперкот |
| Каратист | самый тяжёлый удар | Киай — ударная волна |
| Нак-муай | устойчивость, колено замедляет | Летящее колено |
| Мастер кунг-фу | скорость, прыжки, добивание подбрасывает | Ладонь Ци — луч |
| Тхэквондист | удары ногами, добивание оглушает | Торнадо-кик |
| Дзюдоист | броски, контрбросок после уклонения | Иппон |

У всех стилей взрывное искусство (C) — **Шквал ударов**. Деремся **голыми руками**: удары копят шкалу метра Battle Arts,
каждый 3-й удар подряд — добивание стиля. Боевое искусство тратит 1 деление метра, шквал — 2.

Книги стилей (книга навыка Epic Fight) крафтятся: книга + кожа + железо (боксёр), + белая шерсть + доски (каратист),
+ кожа + кость (нак-муай), + бамбук + перо (кунг-фу), + кожаные ботинки (тхэквондо), + нить + белая шерсть (дзюдо),
и попадаются в сундуках. ПКМ по книге — выучить, затем выбрать стиль в меню навыков Epic Fight.
