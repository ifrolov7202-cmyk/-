# Боевые искусства (Martial Arts) — аддон для Epic Fight, Minecraft 1.20.1 Forge

Рукопашный бой для **Epic Fight**: боевые бинты шести стилей, техники на клавише врождённого навыка Epic Fight,
комбо-добивания, энергия Ци и прокачка мастерства. **Своих клавиш у мода нет** — всё управление через Epic Fight.

## Что нужно

- Forge 1.20.1 (47.x)
- **Epic Fight** 20.14 или новее для 1.20.1 (обязателен — мод его аддон)

## Как играть

1. Скрафти **тренировочные бинты** (2 кожи + 2 нити крест-накрест).
2. Выучи стиль: скрафти **свиток стиля** и нажми ПКМ.
3. Покрась бинты красителем стиля → **бинты стиля**. Бинты работают со стилем, только если он выучен.
4. Включи боевой режим Epic Fight (R) и дерись.

### Управление (клавиши Epic Fight)

| Действие | Что делает |
|---|---|
| ЛКМ | Связки ударов кулаками Epic Fight; каждый 3-й удар подряд — **добивание стиля** |
| Клавиша врождённого навыка | **Особая техника стиля** (15 ур.; до этого — Сокрушительный удар) |
| Shift + навык | **Шквал ударов** — 10 ударов за секунду (10 ур.) |
| Бег + навык | **Вихревой удар ногой** по всем вокруг (5 ур.) |
| Уклонение / блок | Навыки Epic Fight (шаг, перекат, блок, парирование) |

Техники тратят **Ци** и имеют свои перезарядки (видно в HUD слева сверху). Ци восстанавливается сама,
**медитация** (присесть и стоять) — втрое быстрее. Удары и победы в бинтах дают опыт мастерства (1–20 ур.).
С ростом уровня в бинтах растут скорость атаки и бега.

### Стили

| Стиль | Особенности | Особая техника | Краситель |
|---|---|---|---|
| Без стиля (тренировочные) | — | Волна Ци | — |
| Бокс | Ци +75%, мощные добивания | Сокрушающий апперкот | красный |
| Каратэ | Сильнейший удар, Сокрушительный ×1.5 | Киай — ударная волна | белый |
| Муай-тай | Добивание замедляет, меньше отбрасывания | Летящее колено (прыжок до 10 блоков) | оранжевый |
| Кунг-фу | Шире вихрь, добивание подбрасывает, мягкие падения | Ладонь Ци — луч на 16 блоков | зелёный |
| Тхэквондо | Вихрь ×1.4, добивание в голову | Торнадо-кик | синий |
| Дзюдо | После уклонения Epic Fight — контрбросок | Иппон — бросок через плечо | фиолетовый |

Свитки: книга + кожа + железо (бокс), + белая шерсть + доски (каратэ), + кожа + кость (муай-тай),
+ бамбук + перо (кунг-фу), + кожаные ботинки (тхэквондо), + нить + белая шерсть (дзюдо).
Свитки также лежат в сундуках подземелий, шахт, храмов, крепостей, деревень и продаются у странствующего торговца.

**Боксёрская груша** (нить сверху, кожа по бокам, шерсть в центре): удары в бинтах дают опыт и Ци.

### Достижения, команды, настройки

- Вкладка достижений «Боевые искусства» (8 достижений).
- `/martial info`, для операторов: `/martial setlevel <1-20>`, `/martial learnall`, `/martial reset`.
- `config/martialarts-common.toml`: множители урона, Ци, опыта; задевают ли техники игроков; пассивки; свитки в сундуках.

## Сборка

Мод собирается автоматически на GitHub (Actions) при каждом изменении; готовый jar — в ветке `builds`.
Вручную: Java 17, `gradlew build` → `build/libs/martialarts-2.0.0.jar` (на Windows — `build-mod.bat`).
