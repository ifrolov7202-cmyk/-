# Боевые искусства (Martial Arts) — мод для Minecraft 1.20.1 Forge

Рукопашный бой с энергией Ци, четырьмя стилями, техниками на клавишах, комбо и прокачкой мастерства.

## Как играть

1. Скрафти **свиток стиля** (или возьми в творческой вкладке «Боевые искусства») и нажми ПКМ — стиль выучен.
2. Дерись **пустой рукой**: удары получают бонус к урону, копят Ци и опыт мастерства.
3. Каждый 3-й полностью заряженный удар подряд — **добивание комбо** с эффектом стиля.
4. С ростом уровня открываются техники (уровни 1–20).

### Техники (клавиши можно поменять в «Управление → Боевые искусства»)

| Клавиша | Техника | Ци | Перезарядка | Уровень |
|---|---|---|---|---|
| V | Рывок / уклонение — бросок в сторону нажатых W/A/S/D; 0.3 с неуязвимости к атакам | 15 | 1 с | 1 |
| R | Сокрушительный удар — мощный удар с отбрасыванием | 25 | 3 с | 2 |
| G | Стойка — 2 с защиты (−60% урона); первые 0.4 с — **идеальное парирование**: атака отменяется, враг замедлен и ослаблен | 10 | 1.5 с | 3 |
| Z | Вихревой удар ногой — урон и отбрасывание всем вокруг | 35 | 5 с | 5 |
| B | Шквал ударов — 10 ударов за секунду по одной цели | 60 | 15 с | 10 |
| H | **Особая техника** — своя у каждого стиля (см. ниже) | 50 | 12 с | 15 |
| K | Сменить стиль (среди выученных) | — | — | — |

Все техники, кроме рывка, требуют пустую основную руку.
**Медитация:** присядь и стой на месте — Ци восстанавливается втрое быстрее.

**Мастерство:** пока основная рука пустая, с каждым уровнем растут скорость атаки (до +1.0) и скорость бега (до +10%).

### Анимации

Каждая техника проигрывает анимацию тела (видят все игроки рядом, а удары руками — и от первого лица):
рывок, сокрушительный удар, боевая стойка, парирование, пробитая защита, вихревой удар ногой с разворотом на 360°,
шквал ударов, джебы в комбо и своё добивание у каждого стиля (апперкот, гяку-цуки, удар коленом, стойка журавля).

Нужна библиотека **PlayerAnimator** (`playeranimator`, версия для 1.20.1 Forge) в папке `mods` у каждого игрока —
скачать на Modrinth / CurseForge. На сервер её ставить не обязательно.
Если дополнительно поставить **bendy-lib**, будут сгибаться локти и колени.

Анимации лежат в `src/main/resources/assets/martialarts/player_animation/*.json` (формат Emotecraft) —
их можно открыть и поправить в Blockbench с плагином Emotecraft.

### Стили

| Стиль | Особенности | Рецепт свитка (без формы) |
|---|---|---|
| Бокс | Ци восстанавливается на 75% быстрее, сильные добивания | книга + кожа + железный слиток |
| Каратэ | Самый сильный удар рукой, Сокрушительный удар ×1.5 | книга + белая шерсть + доски |
| Муай-тай | Добивание замедляет, меньше отбрасывания, вихревой удар +30% | книга + кожа + кость |
| Кунг-фу | Рывок длиннее, вихревой удар шире, добивание подбрасывает, урон от падения ×0.5 | книга + бамбук + перо |
| Тхэквондо | Вихревой удар ×1.4 и шире, добивание — удар ногой в голову (тошнота) | книга + кожаные ботинки |
| Дзюдо | Окно парирования 0.6 с, парирование бросает врага, добивание — бросок через бедро | книга + нить + белая шерсть |

Свитки также попадаются в сундуках (подземелья, шахты, храмы, крепости, кузницы деревень, аванпосты, особняки)
и продаются у странствующего торговца.

### Достижения и настройки

Вкладка достижений «Боевые искусства»: 9 достижений (первый пояс, ученик, мастер, гранд-мастер, идеальная защита,
уклонение, секретная техника, все школы).

Настройки — `config/martialarts-common.toml`: множители урона, восстановления Ци и опыта, задевают ли техники игроков,
пассивные бонусы, свитки в сундуках.

### Боксёрская груша

Рецепт: нить сверху, по бокам кожа, в центре шерсть (2 ряда). Удары пустой рукой дают опыт и Ци.
Рукой не ломается — снимается топором.

### Команды

- `/martial info` — твой стиль, уровень, опыт, Ци
- `/martial setlevel <1-20>`, `/martial learnall`, `/martial reset` — для операторов (тест)

## Как собрать .jar

**Самый простой способ (Windows):** дважды кликни `build-mod.bat`.
Скрипт сам проверит Java, перенесёт проект в `C:\mods-build` (чтобы русские буквы в пути не ломали Gradle),
соберёт мод и положит `martialarts-1.1.0.jar` рядом со скриптом. IntelliJ IDEA для этого не нужна.

Вручную:

Нужна **Java 17** (JDK; подходят 17–22 — на Java 23+ Gradle 8.8 не запускается). В папке проекта:

- Windows: `gradlew.bat build`
- Linux/macOS: `./gradlew build`

Первая сборка качает Minecraft и Forge (5–15 минут). Готовый мод: `build/libs/martialarts-1.1.0.jar` → положить в `.minecraft/mods`.

Запуск игры с модом прямо из проекта: `gradlew runClient`.

**Если открываешь в IntelliJ IDEA:** `Settings → Build Tools → Gradle → Gradle JVM` = Java 17.
Ошибка `Unable to load class 'org.objectweb.asm.Type'` означает, что Gradle запущен на слишком новой Java
или в пути проекта/пользователя есть русские буквы.

**Без установки Java:** залей проект в репозиторий GitHub — сборку запустит `.github/workflows/build.yml`,
а готовый jar появится во вкладке *Actions → последний запуск → Artifacts*.

## Структура

```
src/main/java/com/martialarts/
  MartialArts.java          главный класс мода
  data/                     Ци, уровень, стили, сохранение (capability)
  skill/                    техники, комбо, опыт — вся серверная логика
  event/CombatEvents.java   бой, парирование, бонусы стилей
  network/                  пакеты клиент ⇄ сервер
  client/                   клавиши и HUD
  item/, block/, registry/  свитки, груша, регистрация
  command/                  /martial
```
