# Боевые искусства (Martial Arts) — аддон для Epic Fight, Minecraft 1.20.1 Forge

Рукопашный бой для **Epic Fight**: шесть стилей, техники на своих клавишах (работают в боевом режиме Epic Fight),
комбо-добивания, энергия Ци и прокачка мастерства.

## Что нужно

- Forge 1.20.1 (47.x)
- **Epic Fight** 20.14 или новее для 1.20.1 (обязателен — мод его аддон)

## Как играть

1. Выучи стиль: скрафти **свиток стиля** и нажми ПКМ (стиль сразу выбирается).
2. Включи боевой режим Epic Fight (его клавиша, по умолчанию R) и дерись **пустой рукой**.
3. Между выученными стилями переключайся клавишей **J**.

### Управление

| Клавиша | Что делает |
|---|---|
| ЛКМ (Epic Fight) | Связки ударов кулаками Epic Fight; каждый 3-й удар подряд — **добивание стиля** |
| Уклонение / блок (Epic Fight) | Навыки Epic Fight (шаг, перекат, блок, парирование); дзюдо после уклонения делает контрбросок |
| **Z** | Сокрушительный удар (1 ур.) |
| **V** | Вихревой удар ногой по всем вокруг (5 ур.) |
| **B** | Шквал ударов — 10 ударов за секунду (10 ур.) |
| **H** | Особая техника стиля (15 ур.) |
| **J** | Сменить стиль |

Клавиши мода работают **только в боевом режиме Epic Fight** и с пустой рукой; по умолчанию они не пересекаются
с клавишами Epic Fight (переназначаются в «Управление → Боевые искусства»).
Техники тратят **Ци** и имеют перезарядки (видно в HUD слева сверху). Ци восстанавливается сама,
**медитация** (присесть и стоять) — втрое быстрее. Удары и победы голыми руками дают опыт мастерства (1–20 ур.),
с уровнем растут скорость атаки и бега.

### Стили

| Стиль | Особенности | Особая техника |
|---|---|---|
| Без стиля | — | Волна Ци |
| Бокс | Ци +75%, мощные добивания | Сокрушающий апперкот |
| Каратэ | Сильнейший удар, Сокрушительный ×1.5 | Киай — ударная волна |
| Муай-тай | Добивание замедляет, меньше отбрасывания | Летящее колено (прыжок до 10 блоков) |
| Кунг-фу | Шире вихрь, добивание подбрасывает, мягкие падения | Ладонь Ци — луч на 16 блоков |
| Тхэквондо | Вихрь ×1.4, добивание в голову | Торнадо-кик |
| Дзюдо | После уклонения Epic Fight — контрбросок | Иппон — бросок через плечо |

Свитки: книга + кожа + железо (бокс), + белая шерсть + доски (каратэ), + кожа + кость (муай-тай),
+ бамбук + перо (кунг-фу), + кожаные ботинки (тхэквондо), + нить + белая шерсть (дзюдо).
Свитки также лежат в сундуках подземелий, шахт, храмов, крепостей, деревень и продаются у странствующего торговца.

**Боксёрская груша** (нить сверху, кожа по бокам, шерсть в центре): удары голой рукой дают опыт и Ци.

### Достижения, команды, настройки

- Вкладка достижений «Боевые искусства» (8 достижений).
- `/martial info`, для операторов: `/martial setlevel <1-20>`, `/martial learnall`, `/martial reset`.
- `config/martialarts-common.toml`: множители урона, Ци, опыта; задевают ли техники игроков; пассивки; свитки в сундуках.

## Сборка

Мод собирается автоматически на GitHub (Actions) при каждом изменении; готовый jar — в ветке `builds`.
Вручную: Java 17, `gradlew build` → `build/libs/martialarts-2.1.0.jar` (на Windows — `build-mod.bat`).
